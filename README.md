## Chrono-Toaster 3000

A catalogue photograph of an impossible gadget: a polished chrome toaster
that toasts **time**. Two slices of toast pop up from its slots as clock
faces — one showing yesterday (10:08, 20 Nov), one showing tomorrow
(2:35, 22 Nov) — with a small hourglass standing beside it as the single
accessory. Shot as a studio product photo on a clean light-grey backdrop,
with an engraved nameplate reading "CHRONO-TOASTER 3000".

## Run it

Requires Node 22+ (stdlib only, no dependencies, no network):

```sh
node main.ts
```

Writes one deterministic 1024×1024 PNG to `/output/entry.png` (≤ 1 MiB,
byte-identical across runs). The program is a small software rasterizer
written from scratch in TypeScript: signed-distance shapes, brushed-chrome
gradients, soft studio shadows, and a hand-rolled PNG encoder.
